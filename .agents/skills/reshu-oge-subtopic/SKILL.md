# Подзадача Решу ОГЭ

Из корня проекта запусти `дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_subtopic.py`, передав ID подзадачи, а не номер ОГЭ и не ID отдельной задачи. Например:

```powershell
python -X utf8 'дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_subtopic.py' 24 --output <путь-к-json>
```

Перед запуском замени `<путь-к-json>` на выбранный путь. Без `--output` JSON-объект с полями `id`, `title`, `amount`, `problem_count` и `problems` выводится в стандартный поток; сообщения о ходе работы и предупреждения идут в поток ошибок. Для большого результата используй файл по запросу пользователя или временный файл для анализа. Каждая задача содержит ID, ссылку, условие и решение в текстовом и HTML-формате; повторяющиеся ID исключаются. `amount` — число из каталога, `problem_count` — число разных ID в подзадаче, включая ссылки `duplicate_problem_ids`.

Скрипт проходит страницы списка сайта. Если он предупреждает, что число полученных задач отличается от `amount` в каталоге, передай это расхождение пользователю и не утверждай, что число совпало. При ошибке не представляй частичный результат как полный.
