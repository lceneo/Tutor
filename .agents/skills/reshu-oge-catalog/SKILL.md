# Весь каталог Решу ОГЭ

Когда пользователь просит именно весь каталог, из корня проекта запусти `дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_all.py`. Полная выгрузка выполняет много последовательных сетевых запросов; дождись завершения процесса.

```powershell
python -X utf8 'дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_all.py' --output <путь-к-json>
```

Замени `<путь-к-json>` на запрошенный пользователем путь либо временный файл для последующего анализа. Без `--output` JSON выводится в стандартный поток; сообщения и предупреждения — в поток ошибок. Результат сгруппирован по номерам ОГЭ и подзадачам сайта, записи `type=extra` исключены. Каждый полный объект задачи выводится один раз; повторные принадлежности отражены через `duplicate_problem_ids`.

Проверь успешное завершение и предупреждения. При расхождении между `amount` и полученным списком сообщи об этом; при ошибке не представляй частичный результат как полный.
