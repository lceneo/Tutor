# Номер задания Решу ОГЭ

Из корня проекта запусти `дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_exercise.py` с номером ОГЭ из поля `issue`, а не с ID подзадачи или отдельной задачи. Например:

```powershell
python -X utf8 'дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_exercise.py' 5 --output <путь-к-json>
```

Перед запуском замени `<путь-к-json>` на выбранный путь. Без `--output` JSON выводится в стандартный поток. В результате — объект с полями `number`, `issue`, `type`, `title`, `amount` и массивом `subtopics`; в подзадачах находятся массивы задач `problems`. При повторении задачи полный объект появляется один раз, а дополнительная принадлежность сохраняется в `duplicate_problem_ids`. Пустые подзадачи сохраняются.

Сохраняй группировку и названия сайта; выводы о содержании делай по условиям задач. Учитывай сообщения в потоке ошибок: если `amount` расходится с фактически полученным числом, сообщи об этом пользователю. При ошибке не представляй частичный результат как полный.
