# Одна задача Решу ОГЭ

Из корня проекта запусти существующий `дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_problem.py`, передав числовой ID задачи. Например:

```powershell
python -X utf8 'дисциплины/ОГЭ/Парсер_Решу_ОГЭ/parse_problem.py' 10383
```

Для сохранения JSON используй `--output <путь>`; для отдельных файлов условия, решения и объединённого файла — `--html-dir <папка>`. Создавай файлы там, где попросил пользователь; если нужно лишь исследовать большой результат, используй временный файл.

JSON содержит `id`, `url`, а также `condition` и `solution` с полями `text` и `html`. `html` — самостоятельный документ, в котором сохранены ссылки на изображения; `text` содержит ссылки на них на соответствующих местах. В HTML используются сетевые ресурсы сайта. При ошибке запроса или отсутствующем блоке сообщи о ней, не выдавая результат за полный.
