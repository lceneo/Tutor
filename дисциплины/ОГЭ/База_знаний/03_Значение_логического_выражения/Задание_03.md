# Задание 3. Значение логического выражения

## Краткая теория

Высказывание бывает истинным или ложным. **НЕ** меняет значение на противоположное; **И** истинно, когда истинны обе части; **ИЛИ** истинно, когда истинна хотя бы одна часть. Если требуется ложность выражения, проверь именно ложность, а не истинность.

| Высказывание | Равносильное после отрицания |
|---|---|
| НЕ (x < a) | x ≥ a |
| НЕ (x ≤ a) | x > a |
| НЕ (x > a) | x ≤ a |
| НЕ (x ≥ a) | x < a |

Для **И** оставь общую часть подходящих значений, для **ИЛИ** объедини их. Учитывай строгие и нестрогие границы, множество допустимых чисел, чётность и делимость. В задачах на количество пересчитай все подходящие значения; в задачах на минимум или максимум проверь ближайшее крайнее значение.

## [Поиск наибольшего значения переменной](https://inf-oge.sdamgia.ru/test?theme=37)

После преобразования условия выбери наибольшее допустимое значение; дополнительные ограничения проверяй отдельно.

**Пример задания** ([№ 10638](https://inf-oge.sdamgia.ru/problem?id=10638))

>**Условие**

Напишите наибольшее целое число x, для которого истинно высказывание:

НЕ (X &lt;= 15) И (X  &lt; 20).

>**Решение**

Запишем выражение в виде

(X &gt; 15) И (X &lt; 20).

Значит, наибольшее число, для которого высказывание будет истинным  — 19.

Ответ: 19.

Приведем другое решение на языке Python.

```python
for x in range(100, 0, -1):
    if not(x <= 15) and (x < 20):
        print(x)
        break
```

**Пример задания** ([№ 10876](https://inf-oge.sdamgia.ru/problem?id=10876))

>**Условие**

Напишите наибольшее целое число x, для которого истинно высказывание:

НЕ (X &lt;= 11) И НЕ (X  &gt;= 17) И (X нечетное).

>**Решение**

Запишем выражение в виде

(X &gt; 11) И (X &lt; 17) И (X нечетное).

Значит, наибольшее число, для которого высказывание будет истинным  — 15.  А наименьшее число, для которого высказывание будет истинным  — 13.

Ответ: 15.

Приведем другое решение на языке Python.

```python
for x in range(100, 0, -1):
    if not(x <= 11) and not (x >= 17) and x % 2 != 0:
        print(x)
        break
```

**Пример задания** ([№ 43350](https://inf-oge.sdamgia.ru/problem?id=43350))

>**Условие**

Напишите наибольшее трехзначное число x, для которого истинно высказывание:

НЕ (первая цифра нечетная) И НЕ (x делится на 3).

>**Решение**

Логическое «И» истинно тогда, когда истинны оба высказывания. Запишем выражение в виде

(первая цифра четная)  И (число не делится на 3).

Значит, наибольшее число, для которого высказывание будет истинным  — 899.

Ответ: 899.

Примечание.

Заметим, что четной должна быть первая цифра числа. Само число может быть как четным, так и нечетным.

Приведем другое решение на языке Python.

```python
for x in range(999, 99, -1):
    if not((x // 100) % 2 != 0) and not(x % 3 == 0):
        print(x)
        break
```

## [Поиск неизвестного числа](https://inf-oge.sdamgia.ru/test?theme=38)

В зависимости от условия требуется найти подходящее число, выбрать его из списка или посчитать подходящие числа.

**Пример задания** ([№ 18242](https://inf-oge.sdamgia.ru/problem?id=18242))

>**Условие**

Напишите число X, для которого истинно высказывание:

(X &lt; 8) И НЕ (X &lt; 7).

>**Решение**

Логическое «И» истинно тогда, когда истинны оба высказывания. Запишем выражение в виде

(X &lt; 8) И (X ≥ 7).

Значит, число, для которого высказывание будет истинным  — 7.

Ответ: 7.

Примечание.

Составителям задания следовало бы уточнить, что требуется написать целое число.

---

**Пример задания** ([№ 35575](https://inf-oge.sdamgia.ru/problem?id=35575))

>**Условие**

Напишите количество натуральных чисел, для которых истинно высказывание:

НЕ (Число &gt; 15) И НЕ (Число четное).

>**Решение**

Логическое «И» истинно только тогда, когда истинны оба высказывания. Запишем выражение в виде

(X &lt;= 15) И  (Число нечетное).

Выпишем подходящие натуральные числа: 1, 3, 5, 7, 9, 11, 13 и 15. Их количество равно 8.

Ответ: 8.

---

**Пример задания** ([№ 36848](https://inf-oge.sdamgia.ru/problem?id=36848))

>**Условие**

Дано четыре числа: 638, 442, 357, 123. Для какого из приведенных чисел истинно высказывание:

НЕ (Первая цифра четная) И (Сумма цифр четная).

>**Решение**

Логическое «И» истинно только тогда, когда истинны оба высказывания. Запишем выражение в виде

(Первая цифра нечетная) И (сумма цифр четная).

Заметим, что 638 и 442  — первая цифра четная, числа не подходят; 357  — сумма цифр нечетная, число не подходит. Значит, число, для которого высказывание будет истинным  — 123.

Ответ: 123.
