## Краткая теория

Сначала прочитай количество чисел, затем обработай каждое число в цикле. Для подсчёта используй счётчик, для суммы — накопитель, для максимума — текущий максимум. Проверь, что начальное значение подходит ограничениям задачи и программа выводит ровно то, что требуется.

**Пример задания** ([№ 37830](https://inf-oge.sdamgia.ru/problem?id=37830))

>**Условие**

Напишите программу, которая в последовательности натуральных чисел определяет максимальное число, кратное 5. Программа получает на вход количество чисел в последовательности, а затем сами числа. В последовательности всегда имеется число, кратное 5. Количество чисел не превышает 1000. Введенные числа не превышают 30 000. Программа должна вывести одно число  — максимальное число, кратное 5.

Пример работы программы:

| Входные данные | Выходные данные |
| --- | --- |
| 3; 10; 25; 12 | 25 |

>**Решение**

Запишем требуемое решение.

```pascal
var k, n, a, amax: integer;
begin
  amax:=0;
  readln(n);
  for k:=1 to n do
  begin
    readln(a);
    if (a mod 5 = 0) and (a>amax) then
      amax:=a;
  end;
  writeln(amax);
end.
```


**Пример задания** ([№ 37831](https://inf-oge.sdamgia.ru/problem?id=37831))

>**Условие**

Напишите программу, которая в последовательности натуральных чисел определяет сумму чисел, кратных 6. Программа получает на вход количество чисел в последовательности, а затем сами числа. В последовательности всегда имеется число, кратное 6. Количество чисел не превышает 100. Введенные числа не превышают 300. Программа должна вывести одно число  — сумму чисел, кратных 6.

Пример работы программы:

| Входные данные | Выходные данные |
| --- | --- |
| 3; 12; 25; 6 | 18 |

>**Решение**

Запишем требуемое решение

```pascal
var n, s, k, g: integer;
begin
  s:=0;
  readln(n);
  for k:=1 to n do
  begin
    readln(g);
    if (g mod 6 = 0) then
      s:=s+g;
  end;
  writeln(s);
end.
```

Приведем решение Павла Шостка на языке Pascal.

```pascal
 readarrinteger(readinteger).Where(x->x.divs(6)).sum.Print;
```

Приведем решение на языке Python.

```python
n = int(input())
sumi = 0
for i in range(n):
    a = int(input())
    if a % 6 == 0:
        sumi += a
print(sumi)
```

```pascal
var n, s, k, g: integer;
begin
```
