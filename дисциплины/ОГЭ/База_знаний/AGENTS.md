# Инструкции для базы знаний ОГЭ

Для поиска файлов заданий используй [содержание базы знаний](Содержание.md). При добавлении, переименовании или перемещении файлов заданий обновляй содержание.

При создании или редактировании файлов заданий используй [шаблон задания](Шаблон_задания.md).

При подготовке материалов с помощью скиллов `reshu-oge-catalog`, `reshu-oge-exercise` или `reshu-oge-subtopic` создавай разделы подзадач по данным, возвращённым скиллом: сохраняй их названия, порядок, вложенность и принадлежность задач. Каждый раздел подзадачи в материале должен соответствовать подзадаче из результата скилла. Самостоятельно выделенные разновидности задач и приёмы решения объясняй внутри соответствующего раздела, не представляя их как отдельные подзадачи каталога. Если возвращена одна подзадача, создай один раздел подзадачи.

При использовании скиллов `reshu-oge-catalog`, `reshu-oge-exercise`, `reshu-oge-subtopic` или `reshu-oge-problem` оформляй каждую задачу по `condition.html` и `solution.html`: извлекай полный текст без сокращений, сохраняя смысл форматирования, таблицы, примеры, ответы и ссылки на изображения. Повторяющийся заголовок «Решение» указывай один раз; остальной текст не сокращай и не пересказывай. Дополнительные пояснения размещай отдельно. Сверь материалы с результатом скилла; временные HTML-файлы и ссылки на них удали.
