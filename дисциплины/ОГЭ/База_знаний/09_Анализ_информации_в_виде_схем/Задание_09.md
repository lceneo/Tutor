## [Поиск путей из одного города в другой](https://inf-oge.sdamgia.ru/test?theme=44)

**Пример задания** ([№ 16017](https://inf-oge.sdamgia.ru/problem?id=16017))

>**Условие**

На рисунке  — схема дорог, связывающих города А, Б, В, Г, Д, Е, Ж, З, И, К и Л. По каждой дороге можно двигаться только в одном направлении, указанном стрелкой. Сколько существует различных путей из города А в город Л?

![Иллюстрация](https://inf-oge.sdamgia.ru/get_file?id=47383)

>**Решение**

Количество путей до города X  =  количество путей добраться в любой из тех городов, из которых есть дорога в Х.

С помощью этого наблюдения посчитаем последовательно количество путей до каждого из городов:

А = 1;

Б = А = 1;

В = А + Б = 1 + 1 = 2;

Д = А = 1;

Г = А + Д = 1 + 1 = 2;

Е = Б + В = 1 + 2 = 3;

Ж = Д + Г = 1 + 2 = 3;

З = В + Г + Е + Ж = 2 + 2 + 3 + 3 = 10;

И = Е = 3;

К = Ж = 3;

Л = Е + Ж + З + И + К = 3 + 3 + 10 + 3 + 3 = 22.

Ответ: 22.

## [Поиск путей из одного города в другой, проходящих или не проходящих через определенный пункт](https://inf-oge.sdamgia.ru/test?theme=22)

**Пример задания** ([№ 10245](https://inf-oge.sdamgia.ru/problem?id=10245))

>**Условие**

На рисунке  — схема дорог, связывающих города А, Б, В, Г, Д, Е, Ж, З и И. По каждой дороге можно двигаться только в одном направлении, указанном стрелкой. Сколько существует различных путей из города А в город И, проходящих через город В?

![Иллюстрация](https://inf-oge.sdamgia.ru/get_file?id=47361)

>**Решение**

Количество путей до города Х = количество путей добраться в любой из тех городов, из которых есть дорога в Х.

При этом если путь должен не проходить через какой-то город, нужно просто не учитывать этот город при подсчете сумм. А если город наоборот обязательно должен лежать на пути, тогда для городов, в которые из нужного города идут дороги, в суммах нужно брать только этот город.

С помощью этого наблюдения посчитаем последовательно количество путей до каждого из городов:

А = 1

Б = А = 1

Д = А = 1

Г = А + Д = 1 + 1 = 2

В = А + Б + Г = 4

Е = В = 4 (Б не учитываем, поскольку путь должен проходить через В)

Ж = В + Е = 4 + 4 = 8 (Г, Д, З не учитываем, поскольку путь должен проходить через В)

З = 0 (поскольку в З не ведет ни одна дорога из В)

И = Е + Ж = 4 + 8 = 12.

Приведем другое решение.

Количество путей из города А в город И, проходящих через город В, равно произведению количества путей из города А в город В и количества путей из города В в город И.

Найдем количество путей из города А в город В:

А = 1

Б = А = 1

Д = А = 1

Г = А + Д = 1 + 1 = 2

В = А + Б + Г = 4.

Найдем количество путей из города В в город И (при этом В - исходный пункт):

В = 1

Е = В = 1

Ж = В + Е = 1 + 1 = 2

И = Е + Ж = 1 + 2 = 3.

Тогда количество путей из города А в город И, проходящих через город В, равно 4 · 3 = 12.

Примечание. Необходимо найти количество различных путей из города А в город И, проходящих через город В.

Ответ: 12.
