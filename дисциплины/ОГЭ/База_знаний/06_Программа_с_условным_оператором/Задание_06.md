# [Задание 6. Программа с условным оператором](https://inf-oge.sdamgia.ru/test?theme=25)

## Краткая теория

Программа получает входные данные, проверяет условие и выполняет одну из двух ветвей: при истинном условии — действие после `if`, при ложном — после `else`. В задаче обычно дано несколько запусков; каждый запуск рассматривается отдельно.

| Запись | Смысл |
|---|---|
| `a > b`, `a < b` | строго больше, строго меньше; равенство не подходит |
| `a >= b`, `a <= b` | больше или равно, меньше или равно |
| `a == b` | значения равны |
| `P and Q` | истинны **оба** условия |
| `P or Q` | истинно хотя бы одно условие, в том числе оба |
| `not P` | условие `P` ложно |

В других языках `and`, `or`, `not` могут записываться как `И`, `ИЛИ`, `НЕ` или `&&`, `||`, `!`. Сначала выясни, при каком условии выводится именно запрошенный ответ: для ветви `else` исходное условие должно быть ложным.

Для отрицания неравенства граница меняется: `not (x > a)` означает `x <= a`, а `not (x < a)` — `x >= a`. По законам де Моргана `not (P and Q)` равносильно `(not P) or (not Q)`, а `not (P or Q)` — `(not P) and (not Q)`.

Удобный порядок решения: определить условие нужной ветви, проверить каждую пару и подсчитать подходящие запуски. Одинаковые пары, встретившиеся несколько раз, считаются отдельно. При подсчёте по `ИЛИ` пару, удовлетворяющую обоим условиям, считают один раз.

## [Задания для подготовки](https://inf-oge.sdamgia.ru/test?theme=25)

В подборке встречаются логические условия, вычисления внутри условия и задачи с неизвестным параметром. Ниже разобраны примеры каждого случая.

**Пример задания** ([№ 10458](https://inf-oge.sdamgia.ru/problem?id=10458))

>*Программа выводит `YES`, если `s > 10` или `t > 10`, иначе — `NO`. Её запустили с парами `(s, t)`: `(1, 2); (11, 2); (1, 12); (11, 12); (−11, −12); (−11, 12); (−12, 11); (10, 10); (10, 5)`. Сколько раз программа вывела `YES`?*

**Решение.** Достаточно, чтобы хотя бы одно число в паре было больше 10. Подходят `(11, 2)`, `(1, 12)`, `(11, 12)`, `(−11, 12)`, `(−12, 11)`. Для `(11, 12)` истинны обе части, но это один запуск. В парах с 10 равенство границе само по себе не подходит.

**Ответ: 5.**

**Пример задания** ([№ 10891](https://inf-oge.sdamgia.ru/problem?id=10891))

>*Программа выводит `YES`, если `s > 6` и `t < 7`, иначе — `NO`. Пары входных чисел: `(7, 3); (2, 7); (6, 10); (5, 3); (5, 4); (−11, 4); (−8, 9); (7, 3); (9, 1)`. Сколько раз будет выведено `YES`?*

**Решение.** Одновременно выполняются оба неравенства в запусках `(7, 3)`, `(7, 3)` и `(9, 1)`. Пара `(7, 3)` указана дважды и даёт два запуска. Число 6 в паре `(6, 10)` не больше 6.

**Ответ: 3.**

**Пример задания** ([№ 37498](https://inf-oge.sdamgia.ru/problem?id=37498))

>*Программа выводит `YES`, если `not ((s < −4) and (t >= 3))`, иначе — `NO`. Пары входных чисел: `(−5, −2); (5, 3); (−14, 3); (−12, 5); (5, −7); (10, 3); (−4, 3); (3, 0); (−4, 9)`. Сколько раз будет выведено `NO`?*

**Решение.** Для `NO` условие после `if` должно быть ложным. Значит, выражение внутри `not` истинно: одновременно `s < −4` и `t >= 3`. Подходят `(−14, 3)` и `(−12, 5)`. В парах с `s = −4` первое неравенство не выполняется.

**Ответ: 2.**

Если в условии есть арифметическое выражение, сначала вычисли его, а затем сравни результат. Для неотрицательных чисел `s // 2` — целая часть частного, а `s % 5` — остаток от деления на 5. В других языках могут использоваться `div` и `mod`; для отрицательных чисел правила деления и остатка зависят от языка.

**Пример задания** ([№ 18215](https://inf-oge.sdamgia.ru/problem?id=18215))

>*Программа выводит `ДА`, если `s // 2 == k`, иначе — `НЕТ`. Её запустили с парами `(s, k)`: `(1, 1); (8, 4); (14, 10); (20, 1); (7, 3); (10, 5); (10, 2); (4, 1); (1, 0)`. Сколько раз она вывела `ДА`?*

**Решение.** Вычисляем целую часть частного для каждого `s` и сравниваем с `k`. Подходят `(8, 4)`, `(7, 3)`, `(10, 5)`, `(1, 0)`: например, `7 // 2 = 3`, а `1 // 2 = 0`.

**Ответ: 4.**

**Пример задания** ([№ 18275](https://inf-oge.sdamgia.ru/problem?id=18275))

>*Программа выводит `ДА`, если `s >= 2 * k`, иначе — `НЕТ`. Пары `(s, k)`: `(1, 2); (8, 4); (6, −12); (−5, −5); (3, 11); (−10, 12); (−10, −2); (4, 1); (2, 5)`. Сколько раз будет выведено `ДА`?*

**Решение.** Сначала удваиваем второе число, затем сравниваем с первым. Подходят `(8, 4)`, `(6, −12)`, `(−5, −5)`, `(4, 1)`. Например, для `(−5, −5)` получаем `−5 >= −10`, а для `(−10, −2)` — ложное неравенство `−10 >= −4`.

**Ответ: 4.**

**Пример задания** ([№ 43715](https://inf-oge.sdamgia.ru/problem?id=43715))

>*Программа выводит `YES`, если `s % 5 == k`, иначе — `NO`. Пары `(s, k)`: `(1, 2); (5, 0); (18, 3); (21, 1); (10, 2); (12, 1); (9, 4); (5, 5); (3, 3)`. Сколько раз она вывела `YES`?*

**Решение.** Остаток от деления первого числа на 5 равен второму в парах `(5, 0)`, `(18, 3)`, `(21, 1)`, `(9, 4)`, `(3, 3)`. Пара `(5, 5)` не подходит: остаток равен 0, а не 5.

**Ответ: 5.**

Параметр `A` имеет одно и то же значение во всех рассматриваемых запусках. Сначала отдели пары, результат которых не зависит от `A`. Затем для остальных выпиши числа, сравниваемые с параметром, вместе с повторами и упорядочь их. Границы интервала проверь подстановкой: знак неравенства определяет, включена ли каждая граница. В конце найди именно то, что требуется: количество, наименьшее или наибольшее значение.

**Пример задания** ([№ 16014](https://inf-oge.sdamgia.ru/problem?id=16014))

>*Программа выводит `YES`, если `s > 10` или `t > A`, иначе — `NO`. Пары `(s, t)`: `(1, 2); (11, 2); (1, 12); (11, 12); (−11, −12); (−11, 12); (−12, 11); (10, 10); (10, 5)`. Для скольких целых значений `A` программа выведет `NO` ровно три раза?*

**Решение.** Для `NO` нужны одновременно `s <= 10` и `t <= A`. Пары с `s = 11` всегда дают `YES`. Для оставшихся семи запусков значения `t` в порядке возрастания: `−12, 2, 5, 10, 11, 12, 12`. Ровно три из них не превосходят `A`, когда `5 <= A < 10`. Целые значения: `5, 6, 7, 8, 9`.

**Проверка:** при `A = 5` подходят три значения `t`, а при `A = 10` — уже четыре.

**Ответ: 5.**

**Пример задания** ([№ 36851](https://inf-oge.sdamgia.ru/problem?id=36851))

>*Программа выводит `YES`, если `s > A` или `t > 12`, иначе — `NO`. Пары `(s, t)`: `(13, 2); (11, 12); (−12, 12); (2, −2); (−10, −10); (6, −5); (2, 8); (9, 10); (1, 13)`. Найдите наименьшее целое `A`, при котором `YES` будет выведено ровно четыре раза.*

**Решение.** Пара `(1, 13)` всегда даёт `YES`, поскольку `13 > 12`. Из остальных восьми запусков нужны ровно три, где `s > A`. Их первые числа по убыванию: `13, 11, 9, 6, 2, 2, −10, −12`. Ровно три из них больше `A` при `6 <= A < 9`: число 6 уже не должно проходить, а число 9 ещё должно проходить. Подходят целые `6, 7, 8`.

**Ответ: 6.**

**Пример задания** ([№ 43583](https://inf-oge.sdamgia.ru/problem?id=43583))

>*Программа выводит `YES`, если `s > A` или `t > 11`, иначе — `NO`. Пары `(s, t)`: `(−9, 11); (2, 7); (5, 12); (2, −2); (7, −9); (12, 6); (9, −1); (7, 11); (11, −5)`. Найдите наибольшее целое `A`, при котором `YES` будет выведено ровно четыре раза.*

**Решение.** Пара `(5, 12)` всегда даёт `YES`. В остальных восьми запусках `t <= 11`, поэтому нужны ровно три значения `s > A`. Упорядочим их: `12, 11, 9, 7, 7, 2, 2, −9`. Подходят значения `7 <= A < 9`: при `A = 7` обе семёрки исключаются, а 9 ещё больше параметра. Целые значения — 7 и 8.

**Проверка:** при `A = 8` подходят `12, 11, 9` и постоянный запуск `(5, 12)`; при `A = 9` число 9 уже не больше `A`.

**Ответ: 8.**
