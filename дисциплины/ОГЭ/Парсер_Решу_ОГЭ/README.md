# Парсер заданий «Решу ОГЭ»

Скрипты используют стандартную библиотеку Python и получают данные с сайта [Решу ОГЭ по информатике](https://inf-oge.sdamgia.ru/). Запускайте команды из этой папки:

```powershell
cd 'дисциплины\ОГЭ\Парсер_Решу_ОГЭ'

# Одна задача: JSON выводится в терминал.
python -X utf8 parse_problem.py 10383

# Сохранить JSON одной задачи в файл.
python -X utf8 parse_problem.py 10383 --output задача_10383.json

# Три HTML-файла: условие, решение и оба вместе.
python -X utf8 parse_problem.py 10383 --html-dir примеры

# Подзадача с метаданными и массивом задач.
python -X utf8 parse_subtopic.py 24 --output подзадача_24.json

# Задание с метаданными и массивом подзадач.
python -X utf8 parse_exercise.py 5 --output задание_5.json

# Массив всех номеров ОГЭ с их подзадачами и задачами, кроме type=extra.
python -X utf8 parse_all.py --output все_задания.json
```

У всех четырёх скриптов параметр `--output` необязателен: без него JSON выводится в стандартный поток вывода, а сообщения о ходе работы — в поток ошибок. Для получения полного каталога потребуется много последовательных запросов и время. При ошибке сайта скрипт завершится с ошибкой. Если количество полученных задач не совпадает с указанным в каталоге, скрипт выводит предупреждение: сайт может возвращать в списке меньше задач, чем указано в `amount`.

В JSON отдельная задача содержит `id`, `url`, `condition` и `solution`. В условии и решении есть поля `text` и `html`; поле `html` содержит готовый HTML-документ. Ссылки на изображения находятся внутри HTML и на соответствующих местах в тексте. Сохранённые HTML-файлы можно открывать в браузере или подключать из Markdown через `iframe`, если просмотрщик поддерживает его.

Категории и их порядок берутся из каталога сайта. Для определения номера ОГЭ используется поле `issue`: у заданий с развёрнутым ответом поле `num` начинается заново. Результат номера ОГЭ содержит `number`, `issue`, `type`, `title`, `amount` и `subtopics`. Результат подзадачи содержит `id`, `title`, `amount`, `problem_count` и `problems`. Поле `amount` — количество из каталога, а `problem_count` — число разных ID, найденных в списке сайта, включая задачи, на которые в этой подзадаче есть только ссылки в `duplicate_problem_ids`. Пустые подзадачи остаются в результате с пустым массивом задач.

Один и тот же ID задачи загружается и возвращается в виде полного объекта только один раз на всю выгрузку. Если он повторно встречается в той же или другой подзадаче, его связь с этой подзадачей сохраняется в поле `duplicate_problem_ids` как ссылка на уже выведенный объект. При запросе отдельной подзадачи её `problems` содержит уникальные задачи.
