# Задание 14. Большой массив данных

**Пример из задания № 10566** ([условие и решение](https://inf-oge.sdamgia.ru/problem?id=10566)): дана таблица с записями о 1000 учениках. В столбцах указаны округ, фамилия, выбранный предмет и тестовый балл. По приложенному файлу нужно:

1. определить, сколько сдававших информатику набрали больше 600 баллов, и записать результат в H2;
2. найти средний тестовый балл сдававших информатику и записать его в H3 с точностью не менее двух знаков после запятой;
3. построить круговую диаграмму по числу участников из округов с кодами «В», «Зел» и «З» и разместить её около G6.

**Разбор по официальному решению сайта:**

- Для первого пункта отбираем строки, где предмет — информатика и балл больше 600. В решении предложено использовать условие `=ЕСЛИ(И(D2>600;C2="информатика");D2;0)`, затем посчитать, сколько подходящих строк получилось. Ответ — **32 ученика**.
- Для среднего используем баллы только по информатике. Сумма в решении — 39 371, число учеников — 72; среднее `39371 / 72 = 546,8194…`, то есть в H3 можно записать **546,82**.
- Для диаграммы сначала подсчитываем число строк каждого нужного округа, затем строим круговую диаграмму по трём полученным значениям и подписываем сектора.

**Запомни:** условия для отбора проверяй по нужным столбцам, а среднее считай как сумму подходящих значений, делённую на их количество. Не включай в расчёт строки, которые не проходят фильтр.
