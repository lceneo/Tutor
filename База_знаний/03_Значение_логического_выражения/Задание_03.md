# Задание 3. Значение логического выражения

В этом задании по логическому условию нужно найти наибольшее или наименьшее целое число либо указать число, при котором условие истинно. Условие обычно задаёт промежуток чисел.

## Краткая теория

Логическое выражение принимает значение **истина** или **ложь**. `НЕ` меняет значение на противоположное; `И` истинно, когда истинны обе части; `ИЛИ` истинно, когда истинна хотя бы одна часть.

| A | B | A И B | A ИЛИ B |
|---|---|---|---|
| ложь | ложь | ложь | ложь |
| ложь | истина | ложь | истина |
| истина | ложь | ложь | истина |
| истина | истина | истина | истина |

Для условий с переменной сначала раскрой `НЕ`:

| Условие | Равносильное условие |
|---|---|
| `НЕ (x < a)` | `x ≥ a` |
| `НЕ (x ≤ a)` | `x > a` |
| `НЕ (x > a)` | `x ≤ a` |
| `НЕ (x ≥ a)` | `x < a` |

`И` означает, что должны выполняться оба ограничения одновременно: ищем пересечение промежутков. `ИЛИ` означает объединение промежутков.

## Как решать

1. Определи, что требуется: наибольшее число, наименьшее или любое подходящее.
2. Замени каждое `НЕ` на противоположное неравенство.
3. Объедини ограничения. Для `И` оставь общую часть промежутков, для `ИЛИ` — все подходящие части.
4. Выбери требуемое целое число. Помни: при целых `x` условие `x > 15` начинается с 16, а `x < 20` заканчивается на 19.

## Поиск наибольшего целого числа

**Пример** ([№ 10638](https://inf-oge.sdamgia.ru/problem?id=10638))

Напишите наибольшее целое число `x`, для которого истинно высказывание:

`НЕ (x ≤ 15) И (x < 20)`.

**Решение.** Раскроем отрицание: `x > 15 И x < 20`. Целые числа, удовлетворяющие обоим условиям, — 16, 17, 18 и 19. Наибольшее из них — 19.

**Ответ: 19.**

## Поиск наименьшего целого числа

**Пример** ([№ 10632](https://inf-oge.sdamgia.ru/problem?id=10632))

Напишите наименьшее целое число `x`, для которого истинно высказывание:

`НЕ (x < 2) И (x < 5)`.

**Решение.** Раскроем отрицание: `x ≥ 2 И x < 5`. Подходят целые числа 2, 3 и 4. Наименьшее из них — 2.

**Ответ: 2.**

## Поиск числа, при котором выражение истинно

**Пример** ([№ 18242](https://inf-oge.sdamgia.ru/problem?id=18242))

Напишите число `x`, для которого истинно высказывание:

`(x < 8) И НЕ (x < 7)`.

**Решение.** Раскроем отрицание: `x < 8 И x ≥ 7`. Если `x` — целое число, подходит только 7.

**Ответ по ключу: 7.** В условии на сайте не сказано, что `x` должно быть целым. Если допустить вещественные числа, подойдут все числа от 7 включительно до 8 не включительно, поэтому ответ не единственный. Это замечание приведено и в разборе задания на сайте; при решении учитывай, что ожидаемый ответ — целое число 7.
