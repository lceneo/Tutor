# Задание 5. Алгоритм для формального исполнителя

## Краткая теория

Формальный исполнитель выполняет команды строго по очереди. Запиши начальное число и после каждой команды полученное значение. Для поиска нужной цепочки удобно идти от стартового числа к цели; если вариантов несколько, подойдёт любой, который укладывается в ограничение.

## Составление последовательности команд

**Пример задания** ([№ 43459](https://inf-oge.sdamgia.ru/problem?id=43459))

Исполнитель умеет уменьшать число на 3 (команда 1) и приписывать справа цифру 1 (команда 2). Подберите не более пяти команд, которые превратят 8 в 15, и укажите их номера. Если решений несколько, допустимо любое.

**Решение.** Выполняем команды `1, 1, 2, 1, 1`:

`8 → 5 → 2 → 21 → 18 → 15`.

Получили нужное число за 5 шагов.

**Ответ: 11211.** Это последовательность из опубликованного решения.

## Нахождение неизвестного параметра

**Пример задания** ([№ 10456](https://inf-oge.sdamgia.ru/problem?id=10456))

Исполнитель Омега имеет команды «прибавить 3» и «разделить на `b`», где `b` — натуральное число не меньше 2. После выполнения цепочки `11121` из числа 30 получилось 6. Найдите неизвестный делитель `b`.

**Решение.** Первые три команды прибавляют по 3: `30 → 33 → 36 → 39`. Четвёртая команда делит на `b`, последняя прибавляет 3. Поэтому `39 / b + 3 = 6`; значит, `39 / b = 3`, откуда `b = 13`.

**Ответ: 13.**

**Проверка:** подставь найденный параметр и пройди команды по порядку; промежуточное деление должно давать допустимое значение.
