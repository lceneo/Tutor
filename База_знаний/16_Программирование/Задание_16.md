# Задание 16. Программа для обработки последовательности

**Пример из задания № 37830** ([условие и решение](https://inf-oge.sdamgia.ru/problem?id=37830)): программа получает сначала количество натуральных чисел (не больше 1000), затем сами числа (каждое не более 30 000). Известно, что хотя бы одно число делится на 5. Нужно вывести наибольшее из таких чисел.

Пример: для последовательности `10, 25, 12` программа выводит `25` (перед числами во входе указано их количество — `3`).

**Решение на Python, по решению сайта:**

```python
n = int(input())
maximum = 0
for _ in range(n):
    x = int(input())
    if x % 5 == 0 and x > maximum:
        maximum = x
print(maximum)
```

**Как это работает:** сначала читаем количество чисел. Затем цикл обрабатывает каждое число: `x % 5 == 0` проверяет делимость на 5, а `x > maximum` оставляет только новое самое большое подходящее число. После цикла выводим максимум. Для примера подходят 10 и 25; большее из них — 25.

**Общий шаблон:** для поиска максимума или минимума храни текущий лучший ответ; для суммы используй накопитель `sum`, для количества — счётчик. Проверяй условие для каждого введённого числа.
