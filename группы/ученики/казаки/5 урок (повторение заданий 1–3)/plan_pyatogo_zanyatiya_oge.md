## Цели занятия

1. Проверить домашние задания на преобразование логических выражений и работу с промежутками.
2. Индивидуально проверить, как группа решает задания 1–3 ОГЭ по пройденным темам.
3. По результатам контрольной определить, что стоит повторить дальше.

## План занятия

| Время | Блок | Содержание |
|---|---|---|
| 0–3 | Вход и настрой | Обозначить порядок занятия: проверка домашней работы, затем индивидуальная мини-контрольная |
| 3–15 | Проверка домашнего задания | Разобрать обе задачи из плана четвёртого занятия; попросить объяснить раскрытие `НЕ`, границы промежутков и выбор крайнего числа |
| 15–18 | Инструктаж | Раздать вариант; напомнить записать ход решения, внимательно читать, какое число требуется найти, и проверить ответы до сдачи |
| 18–43 | Мини-контрольная | Самостоятельно решить задания 1, 2 и 3 из одного варианта; рекомендуемое распределение времени: 7, 8 и 10 минут |
| 43–53 | Сбор и разбор ответов | Собрать работы, сверить ответы и разобрать ключевые шаги по одному заданию за раз |
| 53–60 | Итог | Коротко обсудить, какие типы заданий получились увереннее; отметить темы, которым нужно уделить внимание на следующем уроке |

## Проверка домашней работы

Домашнее задание задано в конце [плана четвёртого занятия](../4%20урок%20(логические%20выражения%20и%20задание%203)/plan_chetvortogo_zanyatiya_oge.md):

1. Наименьшее целое число для `НЕ (x ≤ 4) И (x < 9)`. Ответ: **5**.
2. Наибольшее целое число для `(x ≥ 1 И x ≤ 4) ИЛИ (x > 8 И x ≤ 10)`. Ответ: **10**.

При проверке попросить учеников показать замену отрицания и отдельно назвать числа, подходящие каждой части выражения с `ИЛИ`.

## Мини-контрольная

Использовать один вариант: [Мини-контрольная по заданиям 1–3 ОГЭ](Мини-контрольная_задания_1-3_вариант_1.md). На задания отводится 25 минут. Ключ находится после листа для учеников; сначала собрать ответы, затем перейти к разбору.
