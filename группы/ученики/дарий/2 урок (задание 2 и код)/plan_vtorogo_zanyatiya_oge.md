## ЭТАП 1. РАЗМИНКА И ПРОВЕРКА БАЗЫ (0–10 минут)

### 1.1. Двоичное сложение (4 минуты)
Предложить Дарию решить 2 примера на доске/в тетради с самопроверкой через десятичные числа:

1. **Пример 1 (один перенос):**  
   $$1101_2 + 101_2$$  
   *Ожидаемый ответ:* $10010_2$ ($13 + 5 = 18$).
2. **Пример 2 (каскадный перенос — контроль прошлого урока):**  
   $$1111_2 + 1_2$$  
   *Ожидаемый ответ:* $10000_2$ ($15 + 1 = 16$).

*Методический фокус:* Убедиться, что Дарий сразу делает перенос без сомнений.

### 1.2. Задание 1 ОГЭ (6 минут)
**Задача на доску:**  
> «В кодировке КОИ-8 каждый символ кодируется 8 битами. Ученик написал текст (в нём нет лишних пробелов):  
> *"Рим, Париж, Берлин, Мадрид, Варшава, Лиссабон — города Европы".*  
> Ученик удалил из списка название одного города, а также ставшие лишними запятую и пробел. При этом размер предложения уменьшился на 8 байтов. Найдите вычеркнутый город».

*Решение:* 1 символ = 8 бит = 1 байт. Уменьшилось на 8 байтов $\rightarrow$ исчезло 8 символов. С учётом запятой и пробела (2 символа) длина названия = $8 - 2 = 6$ букв.  
*Ответ:* **Мадрид** или **Берлин** (обратить внимание на наличие вариантов одинаковой длины, выбрать подходящий по условию разделителей).

## ЭТАП 2. РАЗБОР ЗАДАНИЯ 2 ОГЭ РУКАМИ (10–25 минут)

### 2.1. Постановка задачи (прототип ФИПИ № 37187)
Показать Дарию таблицу:

| Буква | А | Е | Л | П | Т | О |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **Код** | `+#` | `#+` | `~` | `#` | `+~#` | `~#` |

**Зашифрованная строка:** `#~#~#++~#`  
**Важное условие:** *В строке закодированы **неповторяющиеся** буквы. Определите исходное сообщение.*

### 2.2. Ручной разбор вместе с учеником
**Вопрос Дарию:** «С чего начнём читать строку `#~#~#++~#`?»

1. Первый символ — `#`.
   - Это может быть буква **П** (`#`).
   - Или начало буквы **Е** (`#+`), но второй символ у нас `~`, а не `+`. Значит, точно **П**.
   - Остаток строки: `~#~#++~#`.
2. Следующий фрагмент:
   - Если взять `~` (буква **Л**), останется `#~#++~#`.
   - Если взять `~#` (буква **О**), останется `~#++~#`.
   - *Вот здесь возникает ветвление!*
3. Показываем, как условие «буквы не повторяются» отсекает ложные ветки:
   - Если мы возьмём путь, где буквы дублируются, мы зайдём в тупик или нарушим условие.
   - Единственное корректное разбиение без повторов:  
     `#` (П) + `~#` (О) + `~` (Л) + `#+` (Е) + `+~#` (Т) = **ПОЛЕТ**.

**Вывод:** Вручную человеку приходится держать в голове возможные варианты развилок и проверять, не использовалась ли буква ранее.

## ЭТАП 3. АНАЛИЗ ИСХОДНОГО КОДА `Решение.ts` (25–40 минут)

Открыть перед Дарием файл [Решение.ts](../../../../База_знаний/02_Кодирование_и_декодирование_информации/Решение_кодом/Шифр_из_символов/Решение.ts):

```typescript
// Разделяем строку на коды из разбора и заменяем каждый код буквой.
let codeSegments: string[] = ["#", "~#", "~", "#+", "+~#"];
let symbolCodes: string[] = ["+#", "#+", "~", "#", "+~#", "~#"];
let decodedLetters: string[] = ["А", "Е", "Л", "П", "Т", "О"];
let decodedMessage: string = "";

for (let segmentIndex: number = 0; segmentIndex < codeSegments.length; segmentIndex++) {
    for (let symbolIndex: number = 0; symbolIndex < symbolCodes.length; symbolIndex++) {
        if (codeSegments[segmentIndex] === symbolCodes[symbolIndex]) {
            decodedMessage = decodedMessage + decodedLetters[symbolIndex];
        }
    }
}
console.log(decodedMessage);
```

### Вопросы для обсуждения с Дарием:
1. **«Как этот скрипт получает ответ?»**  
   Дарий должен заметить: он берёт элементы из массива `codeSegments` и через двойной цикл ищет соответствие индексов в `symbolCodes` и `decodedLetters`.
2. **«А теперь главный вопрос: в чём здесь подвох? Что в этом коде сделано нечестно?»**  
   *Ключевая мысль:* В строке 2 массив `codeSegments` уже содержит готовые кусочки `["#", "~#", "~", "#+", "+~#"]`!  
   То есть человек **руками решил всю задачу**, нарезал строку, а компьютеру оставил только замену символа на букву!
3. **«Что произойдёт, если нам дадут строку из 100 символов с 10 развилками?»**  
   Этот скрипт будет бесполезен, потому что сам он расшифровывать с нуля не умеет.
4. **«Как хранятся соответствия букв?»**  
   Два параллельных массива `symbolCodes` и `decodedLetters` — это неудобно и медленно ($O(N \cdot M)$). В TypeScript для пар «ключ-значение» есть специальная структура.

## ЭТАП 4. БОЛЬШОЙ РЕФАКТОРИНГ: ШАГ ЗА ШАГОМ (40–70 минут)

Вместе с Дарием пишем новый код, двигаясь от простых улучшений к полноценному декодеру.

### Шаг 1. Переход на словарь (Record)
Избавляемся от двух массивов и вложенного цикла:
```typescript
const encodedMessage: string = "#~#~#++~#";

const codeToLetter: Record<string, string> = {
    "+#": "А",
    "#+": "Е",
    "~": "Л",
    "#": "П",
    "+~#": "Т",
    "~#": "О"
};
```
*Что объясняем Дарию:* Объект/словарь связывает код и букву напрямую. Доступ по ключу нагляден и исключает рассинхронизацию индексов.

### Шаг 2. Идея указателя (Pointer) и `startsWith`
Объясняем концепцию считывающей головки:
- Мы стоим в начале строки: `pointer = 0`.
- Проверяем, начинается ли подстрока с позиции `pointer` на какой-то из кодов словаря:
  ```typescript
  encodedMessage.startsWith(code, pointer)
  ```
- Если код подошёл, мы сдвигаем указатель: `pointer + code.length`.

### Шаг 3. Учёт условия «неповторяющиеся буквы» (`Set`)
- Чтобы помнить, какие буквы уже использовались, в программировании используют множество (`Set`).
- Проверка: `!usedLetters.has(letter)`.
- Добавление: `nextUsed.add(letter)`.

### Шаг 4. Управление ветвлением: стек состояний (`Stack`)
**Проблема:** если один код подошёл, но дальше привёл в тупик — компьютеру нужно уметь «откатиться назад» и попробовать другой вариант.

Создаём интерфейс состояния:
```typescript
interface DecodeState {
    pointer: number;         // где мы сейчас в шифровке
    decodedText: string;     // что уже расшифровали
    usedLetters: Set<string>;// какие буквы уже потратили
}
```

И организуем цикл обхода:
```typescript
const stack: DecodeState[] = [
    { pointer: 0, decodedText: "", usedLetters: new Set() }
];

let finalResult: string = "";

while (stack.length > 0) {
    const currentState = stack.pop()!;
    const { pointer, decodedText, usedLetters } = currentState;

    // Успех: дошли до конца всей строки
    if (pointer === encodedMessage.length) {
        finalResult = decodedText;
        break;
    }

    // Пробуем подставить все возможные коды
    for (const [code, letter] of Object.entries(codeToLetter)) {
        if (!usedLetters.has(letter) && encodedMessage.startsWith(code, pointer)) {
            const nextUsed = new Set(usedLetters);
            nextUsed.add(letter);

            stack.push({
                pointer: pointer + code.length,
                decodedText: decodedText + letter,
                usedLetters: nextUsed
            });
        }
    }
}
```
